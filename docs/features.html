L2 · Tools & Actions (server + client side)

L2

Server-side tools (LangChain @tool)

Pure Python functions exposed to the LLM by the LangGraph agent. The POC ships eight tools spanning four domains.

# backend/agent.py
@tool
def finance_summary() -> dict: ...
@tool
def hr_summary() -> dict: ...
@tool
def healthcare_summary() -> dict: ...
@tool
def wireless_summary() -> dict: ...
@tool
def list_tables() -> list[str]: ...
@tool
def table_schema(table: str) -> list: ...
@tool
def select_all_rows(table: str) -> list: ...
@tool
def summarize_table(table: str) -> dict: ...
L2

Client-side actions (useCopilotAction)

Frontend declares typed callbacks the agent can invoke. Drives generative UI.

useCopilotAction({
  name: "selectDomain",
  parameters: [{name:"domain", type:"string", required:true}],
  handler: async ({domain}) => setActive(domain),
});
L2

Readable state (useCopilotReadable)

Pushes UI state into the LLM context every turn so the agent can reason about what the user sees.

useCopilotReadable({
  description: "active domain + per-domain summaries",
  value: { activeDomain, summaries },
});

L5 · Open Generative UI

Idea

No pre-declared component shape. The agent can render arbitrary inline UI through a single renderMarkdown action with a render prop – the foundation for true open-GenUI + MCP scenarios.

useCopilotAction({
  name: "renderMarkdown",
  parameters: [{name:"markdown", type:"string", required:true}],
  render: ({args}) => <pre>{args.markdown}</pre>,
});

Backend wiring

LangGraph agent

A LangGraph create_react_agent compiled graph with the eight tools above. The system prompt lives in prompt_instructions.txt.

# backend/agent.py
agent = create_react_agent(
    model=ChatOpenAI(model="gpt-4o-mini", temperature=0),
    tools=[...8 tools...],
    prompt=get_system_prompt(),
    name="copilotkit-agent",
)

AG-UI mount

The compiled graph is wrapped as an AG-UI agent and exposed by CopilotKitRemoteEndpoint at /api/copilotkit on FastAPI.

# backend/main.py
copilot_agent = LangGraphAGUIAgent(
    name="copilotkit-agent",
    graph=compiled_graph,
    description="Multi-domain SQLite assistant",
)
sdk = CopilotKitRemoteEndpoint(agents=[copilot_agent])
add_fastapi_endpoint(app, sdk, "/api/copilotkit")

Next.js runtime bridge

The Next.js App Router endpoint registers the remote agent via LangGraphHttpAgent and forwards GraphQL traffic to FastAPI.

// app/api/copilotkit/route.ts
import {CopilotRuntime, copilotRuntimeNextJSAppRouterEndpoint,
        ExperimentalEmptyAdapter} from "@copilotkit/runtime";
import {LangGraphHttpAgent} from "@copilotkit/runtime/langgraph";

const runtime = new CopilotRuntime({
  agents: {
    "copilotkit-agent": new LangGraphHttpAgent({
      url: "http://localhost:8000/api/copilotkit/agents/copilotkit-agent"
    })
  }
});

Compatibility shim

copilotkit 0.1.89 calls super().dict_repr() on a base class that lacks it (ag-ui-langgraph 0.0.35). A small monkey-patch in main.py restores the contract.

from ag_ui_langgraph import LangGraphAgent as Base
if not hasattr(Base, "dict_repr"):
    Base.dict_repr = lambda self: {
        "name": self.name,
        "description": self.description or "",
    }
